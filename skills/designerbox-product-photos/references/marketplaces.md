# Marketplace image rules

Rules change. Tell the user the rule you used and where it came from. Points marked "check this page" are not verified here: open the official page, or ask the user to, before promising a result.

## Amazon

Source used: Amazon Seller Central forum post "Product Photography Standards" (posted in Seller Central, it points to the Product Image Requirements Guide for the full rules): https://sellercentral.amazon.com/seller-forums/discussions/t/0149bdb3-2056-42ce-b0bb-9eef94e3d2b8

What that post states for main images:

- Background: "Pure white (RGB 255, 255, 255)".
- Size: "Minimum 1000 pixels on the longest side for zoom functionality; optimal is 1600+ pixels."
- Text and props: "Avoid text, graphics, logos, watermarks, or promotional messaging on main images." In our words, not a quote from the post: show only what is included in the purchase, no props or accessories that are not part of the order.
- Product fill: "Your product should fill 85-100% of the image frame."
- Main-image ratio: not stated there. Check the official guide: https://sellercentral.amazon.com/help/hub/reference/external/G1881

For the full current rules, check the guide above.

## Shopify

Page: https://help.shopify.com/en/manual/products/product-media/product-media-types

- Square product images: "a size of 2048 x 2048 px usually displays best."
- Sizes up to 5000 x 5000 px or 25 megapixels, file size under 20 MB.
- Ratio: use one consistent ratio for all main images so collection pages line up. Shopify names no specific ratio.
- Formats: PNG recommended, JPEG next. Also accepted: TIFF, BMP, GIF, SVG, HEIC, WebP.
- Background, text and props: Shopify sets no rule. Recommendation only: a clean background for the main image, scenes for the rest, no text on the main image.

## Own site

No marketplace rules apply. These are recommendations, not requirements:

- Pick one ratio for all main images (1:1 or 4:5 are common) and check the model gives it in `aspectRatios`.
- Main image: plain or very simple background, product fills most of the frame, no text.
- Extra images: lifestyle, detail and angle shots.
- Export large enough to stay sharp on a phone, and keep the file size modest for page speed.
